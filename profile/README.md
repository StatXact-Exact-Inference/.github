# StatXact — Exact tests on small counts you keep

StatXact keeps one named exact session on the desk: the live counts, the inference step in front of you, and a short note the next analyst can read. Extra tables wait for their own title.

## Session Card

| Slice | What you do in StatXact | What remains |
|-------|------------------------|--------------|
| Arrival | Open StatXact and name today's count session | A titled exact table |
| Focus | Keep only live counts on the StatXact desk | A short table list |
| Check | Read the StatXact summary before a large change | A confirmed exact set |
| Handoff | Mark finished tests inside StatXact | A note for the next count |

## How StatXact Sits

StatXact is not a substitute for the count sheet you already keep. It sits beside that sheet as a named lab desk for one exact job: which categorical table is open, which small sample is pinned, and what the next analyst should read. A local StatXact profile is enough for everyday counts you own or are allowed to analyze.

If two people share a PC, each keeps a StatXact style of their own. The exact table stays small on purpose. Extra counts wait for their own title instead of crowding the live inference.

## Traffic Light

| Signal | On the StatXact board | What you do |
|--------|----------------------|-------------|
| Green | Named table, short count list | Continue the same exact test |
| Amber | Counts from two studies mixed | Split the set before a large change |
| Red | No title, hand calculations everywhere | Stop and name the StatXact session first |
| Clear | Handoff written, counts few | Close StatXact and leave the lab desk |

## Open Order

1. Open the last StatXact session, not a new empty table.
2. Read the count list and the last handoff.
3. Finish one visible exact test inside StatXact.
4. Write what changed, then close with fewer loose counts than you found.
5. If the set feels crowded, drop anything that belongs to a different StatXact job.

## After a Week

By Friday the StatXact table should be smaller, not a stack of scratch counts. It is the same title, a shorter exact list, and a note that still makes sense on Monday.

Other programs stay where they are. StatXact only keeps the path back: session name, counts, summary, handoff. Leave StatXact with a quieter lab desk than the one you opened.

## Sign-off

- [ ] The StatXact session name is short enough to scan
- [ ] Only live counts you keep are on the desk
- [ ] A second person can read the handoff
- [ ] The last StatXact session still opens after a restart
- [ ] Finished tables are off the live StatXact set
- [ ] The StatXact summary still matches the counts on the board

## Field Note

StatXact is clearer when the exact table is smaller than the notebook it came from. Name the session, keep the live counts, finish one visible test, and write what changed. Extra tables wait for their own title.
